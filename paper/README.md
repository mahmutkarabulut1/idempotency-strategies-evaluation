# Manuscript

Two build targets share one body (`body.tex`):

| File | Class | Purpose |
|------|-------|---------|
| `main.tex` | `IEEEtran` (`[journal]`) | **Self-contained** build — compiles with stock TeX Live (`make`). Use for quick review/PDF. |
| `ieeeaccess-main.tex` | `ieeeaccess` (`IEEEaccess.cls`) | **Official IEEE Access submission** version — Access front matter (`\history`, `\doi`, `\corresp`, `\address`, biographies). |
| `body.tex` | — | Shared content: abstract, index terms, all sections, figures, tables, references. Edit content here. |
| `results_table.tex`, `fault_table.tex` | — | Auto-generated by `analysis/make_results_table.py` from measured data; `\input` by the body. |
| `references.bib` | — | Bibliography (IEEE style, `IEEEtran.bst`). |

## Building the self-contained version
```bash
make            # -> main.pdf (needs a LaTeX install: texlive-latex-recommended + IEEEtran)
```

## Building the IEEE Access submission version
`IEEEaccess.cls` and the IEEE Access logo are **not** in stock TeX Live. Obtain the
official template, then drop `ieeeaccess-main.tex` + `body.tex` + the `*.tex`/`*.bib`
into it:
- Overleaf: search "IEEE Access LaTeX template", or
- IEEE Author Center → Templates → IEEE Access (Template Selector).

Then build `ieeeaccess-main.tex` there (Overleaf builds it directly).
